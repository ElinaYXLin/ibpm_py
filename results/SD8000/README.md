# SD8000 airfoil vs. UIUC LSAT experiment

Same methodology as [`results/SD7003/README.md`](../SD7003/README.md) —
read that first for the full setup/limitations discussion. This is the
second of two real cambered-airfoil validation cases (see also
`results/SD7003/`), generated by the same scripts
([`gen_airfoil_report.py`](../SD7003/gen_airfoil_report.py),
[`gen_flowfield_figs.py`](../SD7003/gen_flowfield_figs.py), both live in
`results/SD7003/` and operate on both airfoils).

## Data provenance (confirmed online)

- **Coordinates**: `SURF_test/SD8000/sd8000.dat.txt` (header
  `SD8000-089-88`) matches the file at
  `https://m-selig.ae.illinois.edu/ads/coord/sd8000.dat` (confirmed by
  fetching that URL directly).
- **Performance data**: `SD8000.DRG.txt`/`SD8000.LFT.txt` are in the
  same genuine UIUC LSAT tabulated format as SD7003's (see that
  README for the caveat on not locating the exact hosting volume for
  these specific tables).

## Setup

Identical to SD7003: `length=6, xoffset=-2, yoffset=-1.5`, `dt=0.01`
(`0.005` at the finest grid level), `Re=60800` (UIUC's lowest-Re bin),
boundary resampled to uniform arc-length spacing matched to each run's
`dx` (raw UIUC spacing is again far too non-uniform to use directly —
see SD7003's README for why).

## Files

Same set as `results/SD7003/`: `polar_comparison.png`, `drag_polar.png`,
`grid_convergence.png`, `flow_evolution.png`, `summary.txt`,
`_run_data/`.

## Results

**Lift matches well** across $\alpha=-3.9°$ to $8.4°$ (e.g. at
$\alpha=8.36°$: sim $C_l=0.921\pm0.29$ vs. exp $C_l=1.034$) — see
`polar_comparison.png`. Same qualitative story as SD7003.

**Drag is overpredicted at higher $\alpha$** for the same reasons as
SD7003 (no transition model, under-resolved laminar separation bubble
physics at Re≈60800): at $\alpha=8.36°$, sim $C_d=0.147\pm0.038$ vs.
exp $C_d=0.028$.

**Grid convergence (`grid_convergence.png`)**, at mild
$\alpha=-0.81°$: this case shows an even more dramatic convergence
story than SD7003's. The coarsest grid (dx=0.04) is not just noisy but
gets the *sign* of $C_l$ wrong (sim $-0.149\pm1.22$ vs. exp $+0.065$ —
the error bar is 20x the mean, i.e. the coarse simulation is not
resolving this flow at all), while the medium (dx=0.02) and fine
(dx=0.01) grids both recover the correct sign and converge toward the
experimental value, with the unsteadiness collapsing sharply
(std: 1.22 → 0.31 → 0.045 as dx: 0.04 → 0.02 → 0.01). This is the
clearest evidence in either airfoil case that the coarse-grid
disagreement is a genuine resolution artifact rather than a modeling
error — full numbers in `summary.txt`.

**Same finest-grid CFL divergence** as SD7003 was hit here too (dx=0.01
diverged to `NaN` at `dt=0.01`, fixed the same way with `dt=0.005`) —
see `SURF_test/rerun_fine_log.txt`.

## Limitations

Identical caveat to SD7003: `flow_evolution.png` shows the same
broadband grid-scale noise spreading through the domain at this
Re/resolution — trust the integrated force/convergence numbers over
the flow-field snapshots.
